# 🌱 Emily Sagaiz – Sustentabilidade no Campo

## Projeto Agrinho 2026

Este projeto foi desenvolvido para o **Agrinho 2026** com o tema **Sustentabilidade no Campo**.

O objetivo é conscientizar sobre a importância das práticas sustentáveis na agricultura, mostrando como ações simples podem preservar o meio ambiente, melhorar a produtividade e garantir recursos para as futuras gerações.

---

## 🌿 Temas Abordados

### Compostagem
A compostagem transforma resíduos orgânicos em adubo natural, reduzindo o lixo e enriquecendo o solo.

### Economia de Água
A irrigação eficiente ajuda a economizar água e aumentar a produtividade agrícola.

### Rotação de Culturas
A alternância de culturas preserva nutrientes do solo e reduz a incidência de pragas.

## 📊 Calculadora de Sustentabilidade

O projeto possui uma calculadora simples que permite inserir valores de:

- Compostagem
- Irrigação Eficiente
- Rotação de Culturas

Ao clicar em **Calcular Impacto**, o sistema apresenta uma avaliação do nível de sustentabilidade.

## 🌎 Sustentabilidade no Campo

A sustentabilidade rural busca equilibrar produção agrícola, conservação ambiental e desenvolvimento social.

Práticas sustentáveis ajudam a:

- Preservar o solo.
- Economizar água.
- Reduzir a poluição.
- Melhorar a qualidade dos alimentos.
- Garantir recursos para as futuras gerações.
